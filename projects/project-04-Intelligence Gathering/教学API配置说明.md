# 每位同学使用自己的 API

本教学版不提供共享 API Key。模型服务费用由配置密钥的人承担。

在项目根目录运行：

```powershell
uv run configure_api.py
uv run start.py
```

使用 pip 环境时，把 `uv run` 换成 `.venv\Scripts\python.exe`。工具会要求输入服务地址、模型名和自己的密钥，密钥输入不回显，只保存到本机 `.env`。已有服务需停止并重启后生效。首次使用也可直接复制 `.env.example` 为 `.env` 手动填写。

选择“关闭模型调用”可清空该副本的模型密钥。本地清洗、去重、关键词提取和文件管理仍可使用；AI 摘要、模型生成的研究想法需要有效 API。工具不管理外部 AI Scientist 的独立凭据。

`.gitignore` 已排除 `.env`，但直接压缩整个运行目录仍可能包含它。分享源码时排除 `.env`、data、knowledge、browser_data、日志和虚拟环境。

不要把自己的后端开放给同学共用：即使界面不显示密钥，调用后端的 AI 功能仍会使用服务端密钥。当前版本是单用户本地服务，不具有多用户账户与独立计费隔离；请每位同学独立部署，保持默认 127.0.0.1 监听。

若密钥曾被提交到公开仓库，需到服务商后台撤销并重新生成，仅删除文件不能撤销旧密钥。
