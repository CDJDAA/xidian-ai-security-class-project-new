# 课程任务说明

上游项目：https://github.com/SakanaAI/AI-Scientist-v2

## 运行方法

请按本目录 [README.md](README.md) 及 [WSL2 开发指南](docs/guides/wsl2-setup.md) 的环境配置、依赖安装和启动步骤操作。命令均在本项目目录执行，API Key 使用自己的配置，不提交真实密钥。已有环境、测试及真实模型调用结果见 [2026-11-17 验证报告](docs/reports/2026-11-17/deployment.md)；正式研究实验和完整论文生成仍需单独验证。

## 建议任务（教师可调整）

阅读研究想法生成与实验树搜索流程，在具备上游所需环境后开展受控的小规模实验，记录配置、评价指标和失败情况。

1. 记录环境版本、运行命令和最小示例结果。
2. 完成一项有明确目标的修改，并说明修改前后行为。
3. 提供可复现的验证步骤及局限性。

## 提交要求

遵循课程根目录 README 的分支与提交规范。提交代码及实验报告，保留上游许可证；报告中写明本次使用的上游版本。
