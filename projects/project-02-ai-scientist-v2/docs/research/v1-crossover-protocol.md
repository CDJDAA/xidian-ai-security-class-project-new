## 问题与固定条件

固定 ResNet20 为唯一代理，在 MobileNetV2 与 VGG11-BN 两个目标上，比较同梯度预算的双视图 BSR 与固定步长 MI-FGSM，观察 BSR−MI 的迁移 ASR 均值差何时由负变正。此处“V2”指 MobileNetV2，不是训练检查点 V2 项目。

- 同一批原有 1,000 张类别平衡 CIFAR-10 测试图片、编号和顺序；另报原 pilot200 与 new800。
- BSR 基础种子 42、142、242；batch=20，每批实际种子为基础种子加 batch 编号。
- epsilon=8/255，零起点、非定向 CE、动量 1，BSR 分块 2、旋转 ±10°。
- 每图预算 G=T×M：MI 的 M=1、T=G、alpha=epsilon/10；BSR 的 M=2、T=G/2、alpha=epsilon/T。
- 每个预算的 MI 仅生成一次，BSR 三个种子分别生成，取平均而不取最强种子。全部源攻击生成后才评价目标。
- 图片配对 bootstrap 为 10,000 次、统计种子 20261117；它仅改变区间的数值估计，不增加攻击重复。

首阶段配置：[v1_crossover_targets.json](../../configs/v1_crossover_targets.json)。实际每阶段另建运行目录，冻结配置、IDs、执行源码、资产及缓存哈希。旧实验及用户自己的 `v1_crossover_mine.json` 保留。

## 有限的自适应补点规则

1. 第一阶段扫描 G=20、24、28、32、36、40。
2. 若任一目标在全部第一阶段采样点均为正，则另开第二阶段向下扫描 G=2、4、8、12、16，检查较低预算；2 是本方案固定双视图的最小可行预算。补点同时评价两个目标，不只报告触发它的目标。
3. 合并已完成结果；对任一目标相邻采样点出现均值符号变化的每个区间，补尚未测过的偶数中间点，将该区间宽度细化至 2。负→正与正→负都执行同一补点规则。
4. 停止于上述粗扫描与一轮偶数补点。若没有观察到均值翻转，报告“已采样预算中未观察到交叉”；若出现多个翻转，全部保留，不强行挑一个。不会为制造交叉无限扩展预算或调整步长、种子、epsilon、模型。

这些规则会使用新阶段的目标结果决定后续预算，因此整个流程明确是探索实验，不是未看结果的固定确认实验。新增的目标、配置和预算选择也不能被视为独立验证。

## 解释规则

- 主要指标为各目标原图预测正确样本上的条件迁移 ASR，分母在该目标所有方法间一致。
- 相邻采样点均值由负变正，只能给出本配置下的**采样均值翻转区间**，不自动等于总体交叉点的置信区间。
- 若邻近区间仍覆盖零，须说明换优证据尚不确定；若负端和正端都有区间排除零，可分别报告两端证据，但不能宣称已证明预算函数连续、单调或唯一交叉。
- 允许单调性不成立、多个局部翻转或未观察到翻转。绘图连接点仅供阅读，不以内插交点宣称精确阈值。
- 固定 MI 步长而 BSR 使用 epsilon/T，是本次资源分配方案的一部分，结论条件于这两种优化日程，不单独证明空间增强机制。
- 全部 1,000 张及 new800 此前已经观察过攻击效果；new800 只排除最早 pilot200，不能重新称为新独立测试集。
- 图片 bootstrap 条件于三个已有攻击种子；batch 共享几何、CUDA 旋转反传非完全确定及多重比较均限制结论强度。可另附按 batch 聚类的多重比较敏感性检查，明确属于近似、事后分析。
