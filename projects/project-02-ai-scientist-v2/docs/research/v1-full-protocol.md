# V1 完整实验协议：样本、种子、目标与预算联合扩展

制定日期：2026-11-18，完整实验执行前。沿用 [V1 基础协议](v1-budget-protocol.md) 的攻击机制与评价定义，依据用户要求一次完成 1,000 张、三个 BSR 随机种子、第二目标与多个梯度预算。本文是执行规则，不预写性能结论。

## 1. 冻结的范围

- 数据集 CIFAR-10，源模型为公开预训练 ResNet-20；目标为公开预训练 MobileNetV2 x1.0 和 VGG11-BN。核验固定模型代码、权重哈希、归一化和干净准确率，本轮不训练或微调权重。
- 直接读取[首轮保留的 selection.json](../reports/2026-11-18/v1-budget/selection.json) 的 `final_ids`，保持原 1,000 张及其顺序，每类 100 张；不依据模型表现重抽图片。
- 原 `pilot_ids` 的 200 张是其中子集。本次同时报告 `full1000`、`pilot200`、`new800`；最后一项表示未参与首轮攻击效果评价的 800 张。原预实验已检查全测试集干净准确率，因此不能把这 800 张描述为完全未访问过目标的图片。
- 零扰动起点，非定向交叉熵损失，L∞ 上限 `epsilon=8/255`，原始 RGB 像素 `[0,1]`。动量系数 1，平均视图梯度后按原规则归一化，投影并裁剪像素。
- BSR 沿用每轴 2 个非空条块、±10° 双线性条旋转、零填充，以及条块打乱。对变换的梯度回传到原图坐标；本轮不重新选择变换参数。
- batch=20，保留固定图片顺序。BSR 的几何参数在 batch 内共享；基础种子 42、142、242，每批加批次号。1,000 张共 50 批，三个种子流互不重叠。
- 本轮在完整 1,000 张的固定顺序上重新生成攻击，`pilot200` 是本轮生成结果的子集。由于 batch 和随机几何的对应关系变化，不能把它当作原来独立 200 张运行的 BSR 结果原样复用；原预实验仍保留独立记录。
- MI-FGSM 每个确定性配置运行一次，BSR 每个配置运行三个种子。种子均值不取 best-of，三个攻击种子不代表三次独立训练。

## 2. 矩阵与步长

预算按每张图片的样本–视图梯度评估计数：`G=T×M`。同一视图 batch 中有 20 张图时，反传一次仍计 20 次样本–视图评估。

| G | 原图 MI：T×M | BSR：T×M | BSR：T×M |
| ---: | ---: | ---: | ---: |
| 20 | 20×1 | 10×2 | 5×4 |
| 40 | 40×1 | 20×2 | 10×4 |
| 80 | 80×1 | 40×2 | 20×4 |

上述九个主配置统一采用 `alpha=epsilon/T`。M=1 指原图 MI 端点；对 BSR 采一个随机变换不等于原图 MI。

保留 MI-10（G=10，alpha=epsilon/10）作为较低预算参考。先前预实验已显示步长会影响比较，因此在完整实验开始前，再为每个 G=20/40/80 预先指定一个 MI 固定步长 `alpha=epsilon/10` 的敏感性配置；全部报告，不依据目标结果选择基线。这仍不等于全面调参。

共 13 个方法配置：7 个 MI 配置各执行一次，6 个 BSR 配置各执行三个种子，共 **25 个生成任务**。1,000 张合计 **1,130,000 次样本–视图梯度评估**，开发诊断与预热单列。缓存与后续评价的前向推理不计为攻击梯度，但应记录耗时。

## 3. 运行顺序及缓存

1. 核验资产和源码，保存配置、数据 IDs、原预实验来源、代码与资产哈希、环境以及执行前时间；保存实际源码快照。
2. 只调用源模型完成全部 25 个任务；每份对抗样本保存对应 IDs、标签、配置、种子、实际梯度计数及 SHA256。
3. 生成完成后，依次加载两个目标进行正常推理检查与全部缓存的评价。相同对抗样本复用于目标，不为第二目标重新优化扰动。
4. 支持从完整且哈希匹配的缓存恢复；恢复时保持原冻结清单。参数、IDs、源码或缓存不匹配即拒绝恢复，不覆盖旧实验。
5. 程序在 Ubuntu 的项目副本执行，原始输出指定为 E 盘挂载路径 `/mnt/e/SecAI-code/xidian-ai-security-class-project-new/projects/project-02-ai-scientist-v2/experiments/` 下的全新目录，便于 Windows 直接查看。数据、权重和虚拟环境保留在 Linux 文件系统。

## 4. 指标和解释规则

- 每个目标、每个子集分别报告干净准确率、扰动后准确率、ASR 分子/分母、各 BSR 种子与种子均值。ASR 分母是该目标在该子集原图上认对数；不同目标的分母可以不同。
- 主要比较预先指定的 G=40 结果；其余预算与分配作为已声明的扩展曲线，避免事后只挑收益最高的一格。分别比较 BSR 与同 G 的主 MI，以及固定步长 MI；不能只与低预算 MI-10 比较。
- 对同一图片保留各方法、各随机种子配对关系，采用按图片聚类的配对 bootstrap。区间条件于当前固定权重和三个种子，不包含独立训练不确定性；多个比较的区间作描述性分析，不据此宣称总体最优或所有比较都具备统计保证。
- 对 `full1000` 和 `new800` 分别展示预算–ASR 与实际耗时–ASR 曲线、G=40 对照表、配对差区间。`pilot200` 作为附属记录，完整保留各目标和不利结果。
- 记录 CUDA 同步后的生成时间、显存和预算。BSR 时间展示单个种子生成时间的平均与范围，不把三次重复的总时间当成一次攻击的时间。缓存命中与新生成耗时分别说明。
- 相同 G 不保证相同 FLOPs 或实际耗时；一次实验的时间不构成稳定硬件效率排名。BSR 种子间波动、CUDA 双线性旋转反传可能不确定等限制必须说明。
- 只凭最终 ASR 和梯度次数，不能证明注意力一致、梯度方差降低或过拟合减轻等机制。本轮结论限定于 CIFAR-10、一个 CNN 源和两个 CNN 目标的已测配置。
